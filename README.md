# RCCG King's Court Dublin website

Static site (V2). `index.html` is the home page. Hosted on Vercel; every push to `main` redeploys.

Don't edit these files by hand. The source lives in `~/King's Court`; run `./build-site.sh` there to refresh this folder, then commit and push.

Placeholders in `[square brackets]` still need real church details (address/Eircode, parking, IBAN/BIC, charity number, contact details).
